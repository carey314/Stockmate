# 小票打印方案调研（2026-08）

> 联网调研（12 次检索交叉核实），场景：Flutter iOS App 连小票打印机打销售单/进货单（中国小商户）

## 一、关键结论（选型生死线）

**iOS 上"随便一台蓝牙小票机都能打"不成立**：iOS 不开放蓝牙经典协议(SPP)，第三方 App 只能连 **BLE** 或 MFi 认证设备。便宜的纯经典蓝牙桌面机，安卓能打、iPhone 连不上。国产便携机（佳博/芯烨）普遍双模蓝牙（iOS 走 BLE），**采购时必须选标注"支持苹果"的型号**。

## 二、推荐架构（按风险从低到高）

| 优先级 | 方案 | 说明 |
|---|---|---|
| **P0 单据图片+分享** | 单据渲染成图片/PDF → 微信分享/存相册/AirPrint | 零硬件依赖；渲染代码是 P1/P2 打印的公共底座 |
| **P1 云打印（飞鹅）** | 打印机自己联网(WiFi/4G)，**后端调飞鹅 HTTP API** 推送，2 秒出纸 | 手机和打印机零连接，**iOS 限制彻底无关**；API 免费、机器 ¥200-300（4G 卡 ~¥60/年）；对接约一天；单人维护首选。备选：易联云 K4/K6 |
| **P2 直连打印** | 蓝牙 BLE：bluetooth_print_plus 或 print_bluetooth_thermal（活跃维护，iOS 走 BLE）；网口：TCP 9100 直连（flutter_esc_pos_network） | 给已有打印机的用户兜底 |

## 三、市场与技术要点

- **主流品牌**：佳博 Gprinter、芯烨 Xprinter、汉印 HPRT；58mm 是小商户绝对主流（¥80-200[推断区间]），80mm 用于餐饮后厨
- **商米 Sunmi**：自带打印机的安卓收银机路线，其插件 Android only——**iOS App 用不上**
- **插件生态**：esc_pos_bluetooth 已死（2021 停更）勿用；活跃的是 bluetooth_print_plus / print_bluetooth_thermal
- **AirPrint 小票机**：国产基本没有认证（只有 Star 等国外数千元机型），此路不通
- **中文打印坑**：ESC/POS 打 GBK 需正确 code page，杂牌机字符集支持参差；**兜底方案 = 渲染成位图再打**（GS v 0 光栅指令，58mm 头 384 点宽）——彻底绕开编码/字体坑，中文/logo/二维码全稳，代价是蓝牙传输慢几秒
- **BLE 坑**：各厂 GATT UUID 不统一、MTU 分包——选活跃插件已处理

## 四、落地顺序（StockMate）

1. P0：单据图片生成 + share_plus 分享（并入单据体系任务 #8）
