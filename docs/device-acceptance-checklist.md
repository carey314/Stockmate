# 真机验收清单（上架前必跑，约 30 分钟）

模拟器验证不了的四件事。全部通过才提审——语音/拍照/打印是提审文案里写的三板斧，
上架后第一批用户点不通就是一星差评。

准备：一台真 iPhone（iOS 15.5+）、一台 58mm 蓝牙热敏打印机（ESC/POS 协议，市面 ¥100 左右的都行）。
打正式包记得带 `--dart-define=API_BASE=https://qxju.shop/mate-api/api/v1`（忘传=废包，连的是 localhost）。

## 1. 语音口述（约 8 分钟）

模拟器上语音必失败是苹果限制，真机才是第一次真验。

- [ ] 首页 → 口述记账 → 点麦克风 → 系统弹语音权限 → 允许
- [ ] 说一句：**"老王拿了两件泸州老窖，收了微信"** → 识别文字基本正确 → AI 解析出草案（客户=老王、已收款）
- [ ] 说带小数的：**"卖了半斤芹菜馄饨"** → 数量 0.5 不报错
- [ ] 连续说 20 秒长句 → 不卡死、不丢字
- [ ] 中途按停止 → 不弹"引擎没启动"的误报
- [ ] 拒绝语音权限后再进 → 有人话提示 + 键盘输入兜底可用

## 2. 拍照 OCR（约 5 分钟）

- [ ] 进货单页 → 拍单据 → 相机权限弹窗 → 拍一张真实的手写/打印送货单
- [ ] 识别结果能铺进单据（商品/数量/单价至少对一半以上——OCR 不完美没关系，能改就行）
- [ ] 商品编辑页 → 商品图 → 拍照/相册二选一都能用

## 3. 蓝牙小票打印（约 10 分钟）⚠️ 最高风险项

PrinterService 从未在真硬件上跑过。

- [ ] 设置 → 打印机 → 蓝牙扫描能发现打印机 → 配对连接成功
- [ ] 订单详情 → 打印小票 → **出纸**，检查：店名抬头 / 商品行 / 金额 / 不是乱码
- [ ] 连续打 3 张 → 不断连、不重影
- [ ] 关打印机再打 → 有人话报错（不是转圈卡死）
- [ ] 58mm 纸宽下小票内容不被截断（光栅 384 点是按 58mm 算的）

## 4. 收摊提醒（约 5 分钟，等一天更稳）

- [ ] 开一单 → 弹"要每天提醒你收摊记账吗" → 好 → 系统通知权限弹窗 → 允许
- [ ] 通知 → 提醒设置 → 改时间到 2 分钟后 → 锁屏等 → **通知真的响**（横幅+声音）
- [ ] 关掉开关 → 到点不响
- [ ] （可选，等 3 天）3 天不打开 App → 召回通知响一次

## 5. 顺手全检（约 5 分钟）

- [ ] Apple 登录真机走一遍（sign_in_with_apple 模拟器行为不同）
- [ ] 扫码开单：扫一个真实商品条码（模拟器无摄像头，从未真验）
- [ ] 弱网（关 Wi-Fi 用蜂窝）下开一单：不丢单、报错是人话
