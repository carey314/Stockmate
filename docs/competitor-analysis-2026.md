## 二、差距清单（P0 = 六家全有、我们没有 = 拿不上桌）

### P0（立刻做）
1. **单据打印/分享**：先做"单据图片/PDF→微信分享"，蓝牙小票机第二步（竞品把远程打印当付费点=刚需铁证）
2. **退货单**（销售退+进货退）：没有它库存与应收算不平
3. **基础报表**：销售明细 / 库存汇总 / **客户应收欠款对账单**（赊销场景与开单同权重）

### P1（竞品收费墙=我们的卡位机会）
4. 多员工权限（竞品最一致的收费墙→支撑我们付费档）
5. 盘点模块化
6. 商品图片管理（智慧记连图片都锁付费→我们免费即宣传点）
7. 多门店（智慧记2299档核心卖点，垂直个体户需求弱，末位）

### P2：微商城/小程序、外勤、电商ERP对接——不做
