## 关键侦察结论
1. **AI是"贴上去的"不是原生的**：AI开单藏在销售单页三级入口；**语音开单连官方教程都没有**（真空地带！）；AI建库不支持多单位多仓；AI助手疑似预设报表非自由问答
2. **9大报表清单**（300万商户教育出的心智，照此对齐）：经营利润/销售统计/热销分析/员工业绩/进货统计/库存统计/客户对账单/供应商对账单/资金流水
3. **口碑**：夸=替代Excel、送货现场开单打印、多端云同步；骂=收费背刺(限单史)、闪退卡顿、客服没人管、双App割裂、导入导出难(有用户写Python拆表)
4. **他们最聪明的设计**：开单即建品（输入不存在的商品自动创建，零冷启动）+ 识别三态确认流

### ② 做得比它好（差异化主战场）
1. **AI原生入口**：我们首页就是麦克风✅（它藏三级）；升级方向：连续多商品口语+上下文记忆（"老王拿两件飞天，按上次价"——**"上次价"自动查该客户历史成交价**）
2. **AI真Agent问数**："这个月谁欠我最多钱""茅台还能卖几天"自由问 + 补货提醒直接生成进货单草稿（它只有预设报表）
3. **诚实定价当卖点**：承诺"免费额度永不回收+数据随时全量导出"（打它收费背刺史）
4. **稳定+断网韧性**：断网也能查库存、看客户，购物车不丢、恢复网络再提交（诚实口径：不承诺离线开单——那需要本地库+双向同步，成本极高且容易造成两端账不一致，明确不做）
5. **智慧记一键搬家**：吃它的Excel导出格式做导入器（它的用户被烂导入折磨到写Python）——虹吸不满用户
