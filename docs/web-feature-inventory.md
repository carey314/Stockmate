# 智存-AI进销存 Web 端产品功能盘点（供内容推广规划用）

> 盘点口径：2026-08-18 线上版本（qxju.shop/mate）。只写代码中已实现、真实可用的功能；
> 未实现/部分实现/待确认均如实标注。由 Web 端开发窗口基于源码与真实回归测试出具。

# 一、Web 产品定位

Web 端是「智存」的**电脑管理后台**：老板在电脑大屏上做手机上不方便的事——批量改商品、看报表、打印对账单、批量导入、管员工。适合有电脑办公习惯的小店老板和批发商户。在整体产品中定位是**配角**：手机 App 负责柜台前的开单收钱（扫码/语音），Web 负责坐下来管货、看账、对账；**两端同一账号、同一套数据、实时互通**。

# 二、Web 页面与菜单结构

左侧菜单从上到下（真实菜单名）：

### 1. 工作台
- 作用：今天生意一眼看清
- 区域：4 张指标卡（今日销售额 / 今日订单数 / 今日毛利* / 库存预警，数字滚动动画，销售额与订单卡右下角带 7 日迷你趋势线）＋「销售趋势」折线图（7 天/30 天/90 天切换，销售额+订单数双线）＋ 缺货时出现「该补货了」卡（列出缺货规格，一键跳新建进货单）＋ 新店三步引导卡（商品数为 0 时出现）
- 员工看到的第 3 张卡是「在售商品」而非「今日毛利」
- 毛利卡在有商品没填进价时提示「其中 ¥X 的货没填进价」
- 实现状态：完整

### 2. 待办
- 作用：今天要处理的事聚合在一页
- 区域：今日小结（销售额/订单/毛利）、该补的货（低于预警线的规格清单）、谁欠我钱（客户欠款）、我欠谁钱（欠供应商货款）；全空时显示「太好了，没有待办事项」
- 只读聚合页，不直接操作
- 实现状态：完整

### 3. 商品管理
- 作用：商品（SPU）与规格（SKU）的批量维护主场
- 区域：品类 Tab 筛选（含「低库存」视图）＋ 搜索框（名称/编码/条码，有关键词时跨品类搜）＋ SPU 表格（展开行显示 SKU）
- 可操作：新增商品（按品类动态字段表单）、编辑商品、删除商品（仅老板）、商品图上传、SKU 行内直改（价格/成本/条码/预警线）、库存数字直改（走库存调整留流水）、加规格、**勾选多商品后：批量改价（按比例/定额）、批量删除（仅老板，软删）**
- 实现状态：完整（规格值组合编辑留在 App，Web 不支持改已有规格的维度组合）

### 4. 品类管理
- 作用：行业配置中心——品类决定商品有哪些字段和规格维度
- 区域：品类卡片列表（显示字段清单/规格维度/商品数/预设与主营标记）
- 可操作：新建品类（含「✨AI 配字段」：输入行业描述，AI 生成两层字段草案，可手工增删改后保存）、编辑品类（字段全量重建）、删除品类（有商品时禁止）、设为主营（商品/盘点/导入等页默认落在主营品类）
- 实现状态：完整

### 5. 往来单位
- 作用：客户与供应商档案，围绕「欠款」组织
- 区域：客户/供应商双 Tab（tab 状态进 URL）＋ 搜索 ＋ 按欠款降序列表 ＋ 顶部总欠款条
- 客户行可展开：近 90 天常买、专属价列表（可新增/删除专属价，支持区分同商品不同规格）、未清单据
- 可操作：新建/编辑/删除客户与供应商、设专属价
- 实现状态：完整（客户/供应商无独立详情页，用展开行承载）

### 6. 订单管理
- 作用：管理已开的销售单（**开单本身在手机 App**，页面上有明确提示）
- 区域：状态筛选（全部/有欠款/已作废，进 URL）＋ 日期范围 ＋ 搜索框（单号/客户名模糊）＋ 订单表格 ＋ 详情抽屉
- 详情抽屉可操作：收欠款（部分/全额，选结算账户）、退货（按行选数量，防超退）、作废（回退库存、已收款自动生成退款流水）
- 支持 `?id=` 深链直开详情（收益日历/全局搜索跳转用）
- 实现状态：完整（Web 无手动开单界面；销售单可经「文本记账」AI 生成）

### 7. 进货管理
- 作用：进货单全流程
- 区域：筛选（全部/欠供应商/已作废）＋ 日期 ＋ 搜索（单号/供应商）＋ 表格 ＋ 详情抽屉
- 可操作：**新建进货单**（选供应商、加商品行、录数量进价、记已付与结算账户）、付欠款、退货给供应商、作废
- 实现状态：完整

### 8. 盘点
- 作用：对库存做实盘核对
- 可操作：新建盘点（列全部 SKU 填实盘数，提交即完成，差异自动落库存并留「盘点盘盈/亏」流水）、查看历史盘点单详情（账面/实盘/差异、盘盈盘亏合计）
- 实现状态：完整

### 9. 收支记账
- 作用：与库存无关的收入/支出台账（房租、水电、日结营业额等）
- 区域：收入/支出双 Tab（进 URL）＋ 日期预设（今天/近7天/近30天/本月）＋ 区间合计条 ＋ 表格
- 可操作：记一笔（快捷分类）、删除
- 实现状态：完整

### 10. 文本记账（AI）
- 见「三、AI 能力」第 1 条
- 实现状态：完整

### 11. 报表大屏
- 见「六、报表体系」
- 实现状态：完整

### 12. 收益日历（仅老板可见）
- 作用：按天看钱的进出（现金口径，与资金流水同一套数）
- 区域：月/周双视图切换＋前后翻页＋回今天＋顶部本月/本周收支净汇总条
- 月视图：月历格子显示每日净额＋事件小卡（超 3 张折叠「+n 笔」）；周视图：7 列看板逐笔铺卡
- 点某天开抽屉：日/月/年三级累计＋逐笔清单（时间/类型/账户/金额，超 30 笔分页），带单号的行可直接跳转打开订单/进货单详情
- 实现状态：完整

### 13. 对账单
- 作用：给客户/供应商出正式对账单
- 区域：客户对账单/供应商对账单双 Tab ＋ 选对象（欠款多的排前）＋ 日期区间 ＋「打印 / 存 PDF」按钮（A4 打印排版）
- 对账单结构：期初余额＋期间往来（退货以带时间戳的红冲行核销，历史单据金额不被追溯改写）＋期末余额
- 实现状态：完整

### 14. 批量导入（AI）
- 见「三、AI 能力」第 4 条
- 实现状态：完整

### 15. 设置
- 区域：店铺信息（店名/主营品类，仅老板）、员工管理（仅老板：新建员工账号/启停用/重置密码）、外观与语言（主题色 5 选/文字大小 3 档/中英文切换，本机偏好）、修改我的密码（全员）
- 实现状态：完整

### 全局能力（不占菜单）
- **Cmd/Ctrl+K 全局搜索**：页面导航＋商品＋客户＋订单号四组结果，↑↓+回车跳转，商品/客户结果跳对应页并自动带关键词过滤，订单结果直开详情抽屉
- 顶栏：日期、全局搜索按钮、导出数据（仅老板，JSON 全量）、专业版徽章（订阅后显示，含到期时间）、店名与角色标识
- 右栏：最近动态（开单/出入库实时流）＋ AI 问生意（仅老板）；两区高度可拖拽调节，整栏可收起
- 浏览器标签页标题跟随页面；页面崩溃有兜底卡片不白屏；多标签登录态同步；A 标签登出 B 标签同步下线

# 三、AI 能力（Web 端全部 4 项，全部真实可用）

### 1. AI 文本记账（菜单「文本记账」）
- 触发：粘贴/输入自然语言 → 点「AI 解析」
- 三种模式：随手记（进/销/支混着说）、客户订货消息（全按卖出）、供应商送货单（全按进货）
- 输入示例：`老王拿了2件泸州老窖，收了微信\n进了30斤面粉花了90块\n摊位费50`
- AI 做什么：拆成销售/进货/支出/汇总营业额四类草案；识别客户并按客户分单；价格三级解析（专属价>上次成交价>标价）；识别收没收钱
- 输出：可勾选可改的草案表格（单价可改、收款状态可选：已收款/挂账（先欠着）/默认——散客默认已收、记名客户默认挂账，列头有规则说明）
- **没有商品档案的条目可勾「顺便建档」**：确认时自动创建商品档案并真扣库存/入库（销售/进货都支持）
- 人工确认：必须点「确认入账勾选的项」才落库；AI 只出草案
- 限制：AI 绝不编成本价；退货/换货不处理（提示去订单里退）；消耗 core 每日额度
- 未确认离开页面会拦截误刷新

### 2. AI 问生意（右栏，仅老板）
- 触发：右栏输入框提问，或点快捷问题（今天卖了多少/谁欠我钱/什么货该补了）
- AI 做什么：基于本店真实经营快照回答（含确定性补货建议：近14天日均销速×7天 vs 库存），支持追问（带最近 3 轮上下文，「那昨天呢」能理解）
- 输出：对话气泡；答不了会诚实说；聊天记录 session 内保留
- 限制：数字必须来自快照（提示词铁律）；消耗 other 额度

### 3. AI 配字段（品类管理 → 新建品类 → ✨AI 配字段）
- 触发：输入行业描述（如「卖螺蛳粉的」）
- AI 做什么：生成该行业的两层字段草案（商品描述字段 + 规格维度，含「是否产生库存」标记——奶茶的温度/糖度不产生库存规格）
- 输出：可编辑的字段草案，人工确认后建品类
- 限制：消耗 other 额度

### 4. AI 批量导入（菜单「批量导入」）
- 触发：选品类 → 粘贴 Excel 整片或任意格式清单文字 → 点「AI 解析」
- AI 做什么：解析成商品草案（名称/规格/卖价/进价/初始库存/品类字段）；解析不了的行原样列出绝不瞎编；只提取用户数据里的真实成本，不编造
- 输出：三步流程（粘贴数据→确认草案→入库完成），勾选后批量入库，失败明细单列
- 限制：消耗 other 额度；未入库草案离开页面有拦截

### Web 端没有的 AI（在 App 上）：语音口述（Web 用打字替代）、拍照 OCR 识别送货单

### AI 通用机制
- 四个 AI 入口都显示当日剩余次数标签（剩 ≤2 次变橙色）；专业版显示「专业版 · 不限次」
- 免费额度用完（402）：弹升级引导弹窗（后端原文+专业版说明+价格+免费承诺）；员工看到的版本不含升级按钮，只提示联系老板
- AI 出口有清洗层（服务端），AI 输出过清洗才落库

# 四、核心进销存功能（老板实际能拿它做什么）

### 商品管理
批量维护商品资料：改价、改成本、改条码、传商品图、改预警线，几十个商品十分钟理完——这是 Web 比手机强的核心场景。

### 商品分类（品类）
按行业组织商品；换行业=新建一个品类让 AI 配字段。品类决定商品录入表单长什么样。

### SKU（规格）
一个商品多规格（整箱/单瓶），价格/成本/条码/库存全在规格上；无规格商品自动有「默认规格」。表格展开行逐规格直改。

### 销售
Web **不做手动开单**（开单在 App：扫码/语音更顺手）；但可通过 AI 文本记账生成销售单（粘贴客户订货消息一键成单）。

### 销售订单
查所有单、按欠款/日期/关键词筛、收欠款、按行退货、作废。老板用它做的事：追欠款、处理退货、纠错。

### 销售退货
订单详情里按商品行选数量退，库存回增、应收冲减、多收部分退款；防超退。

### 进货 / 采购订单
Web 可完整新建进货单（选供应商+商品行+已付款），也可后续补付欠款。

### 采购退货
进货单详情「退货给供应商」：库存扣减、应付冲减。

### 库存
规格级库存实时显示；低库存视图；所有变动都有流水（谁、何时、为何）。

### 库存调整
商品页直改库存数字即为调整（强制走调整接口留「手动调整」流水，不能悄悄改数）。

### 库存盘点
新建盘点单填实盘数，提交自动把差异落进库存并留盘盈/亏流水。

### 扫码
Web 无扫码（App 功能）。

### 客户
档案+欠款排序+常买记录+专属价（可按规格设不同价）+未清单据。老板用它：催账、给熟客固定优惠价。

### 供应商
档案+欠款（我欠谁钱）排序。

### 欠款
双向：客户欠我（订单收欠款）、我欠供应商（进货付欠款）；待办页和往来单位页都有汇总。

### 收付款
每笔收款/付款/退款独立流水（含时间戳、结算账户：现金/微信/支付宝/银行卡/挂账）；资金流水报表与收益日历同源。

### 账单
客户/供应商对账单（期初+往来+期末），A4 打印/存 PDF，可直接发给对方对账。

### 其他
收支记账（房租水电等非库存收支）、收益日历（按天看钱进出）、全量数据导出（JSON）。

# 五、行业能力

- **AI 行业配置**：新建品类时输入任意行业描述，AI 生成字段与规格维度——这是「30 秒配成自己行业」的落地，不限于预设行业
- **自定义字段**：品类字段可手工增删改（文本/数字/下拉/日期/布尔，必填与否，是否产生库存规格）
- 开发种子中验证过的行业配置（真实存在的字段模板案例）：酒水（品牌/子类/年份/产地+规格/酒精度）、药品（品牌/生产厂家/批准文号/剂型/处方类型/有效期至）、玩具（适用年龄/材质/安全认证）、餐饮食材（储存方式/保质期）、奶茶（规格/温度/糖度——温度糖度不产生库存）、气球、火鸡面、馄饨类鲜食
- 药店/服装/母婴/五金/批发：**没有预置模板**，但 AI 配字段可以现场生成（能力真实，具体行业模板不是内置资产）——宣传时应表述为「AI 现配」而非「内置 N 个行业」

# 六、报表体系

报表分布在三个地方：报表大屏（6 张卡）+ 对账单页（2 类）+ 收益日历（1 页）。

| # | 名称 | 数据内容 | 回答什么问题 | 筛选 | 导出 | 状态 |
|---|---|---|---|---|---|---|
| 1 | 经营利润 | 销售额/销货成本/经营支出/利润/订单数+双线趋势图；另列损耗金额（报损/过期） | 这段时间赚了多少 | 今天/近7天/近30天/本月/自定义区间（进 URL 可分享） | 无单独导出 | ✅ 仅老板 |
| 2 | 销售统计（按商品） | 每商品销量/金额/毛利+横向条形图（热销排序） | 什么货最好卖、哪个最赚 | 同上日期 | 无 | ✅ 全员 |
| 3 | 库存统计 | 库存总值(按成本)/总件数/规格数+低库存规格表 | 压了多少钱的货、什么该补 | 时点数据不受日期影响 | 无 | ✅ 全员 |
| 4 | 进货统计 | 进货金额/单数/明细 | 这段时间进了多少货 | 同日期 | 无 | ✅ 全员 |
| 5 | 资金流水 | 每笔真实收付款（排除冲账），按账户 | 钱从哪来到哪去 | 同日期 | 无 | ✅ 仅老板 |
| 6 | 员工业绩 | 按操作员统计开单业绩 | 谁卖得多 | 同日期 | 无 | ✅ 仅老板 |
| 7 | 客户对账单 | 期初+期间单据/收款/退货红冲+期末 | 和客户对总账 | 客户+日期区间 | **A4 打印/存 PDF** | ✅ |
| 8 | 供应商对账单 | 同上（应付方向） | 和供应商对总账 | 供应商+日期区间 | A4 打印/存 PDF | ✅ |
| 9 | 收益日历 | 按天现金进出（月/周视图+逐笔） | 哪天进钱多、哪天亏 | 月/周翻页 | 无 | ✅ 仅老板 |

数据导出：顶栏「导出数据」= 全量 JSON（仅老板）。**Web 无 CSV 导出**（App 有 CSV 6 表）。

# 七、员工与权限

- 角色两种：**老板（admin）/ 员工（staff）**；员工账号由老板在 设置→员工管理 创建（用户名+密码），可启停用、重置密码
- 多员工同时使用：支持（各自账号并发登录，App/Web 均可）
- **老板与员工看到的区别（Web 端）**：

| 内容 | 老板 | 员工 |
|---|---|---|

# 八、数据管理

- 存储：云端服务器（所有端连同一后端）；多租户按店隔离（每店数据互不可见，21 张业务表逐店隔离并有 22 项回归测试）
- 同步：App/Web 实时同一数据库，无同步延迟概念
- 导入：AI 批量导入（粘贴 Excel/文本）
- 导出：全量 JSON（Web，仅老板）；App 另有 CSV 6 表。「数据永远是你的，随时全量导出」是公开承诺
- 备份：服务器每日自动备份保留 30 天，含完整性自检，做过真实恢复演练（服务端运维能力，用户无自助入口）
- 迁移：无自助迁移工具（导出 JSON 可作数据带走的兜底）
- 删除：删除账号在 App 内（我的→账号与安全→删除账号，两步确认）；最后一个用户删号=全店数据清除
- 恢复：删除不可自助恢复（删除前有导出提示）

# 九、账号体系

- 注册：**仅 App**（注册即建店，Web 登录页明示「暂不支持在网页注册」）；App 支持 Apple 登录
- 登录：Web 用户名+密码；有「忘记密码?」引导（员工找老板重置/老板走支持页人工核实；无短信自助找回）
- **App/Web 同账号同数据：是**（同一后端同一 JWT 体系，实测验证）
- 店铺体系：一个账号属于一家店；权益（订阅）挂在店上,全店共享
- 多店铺：**不支持**一个账号管多店（要多店需注册多个账号）
- 多设备：支持同时登录；Web 多标签登录态同步（一处登出全下线）

# 十二、真实老板使用场景

1. **场景**：月底想知道这个月到底赚了多少。**解决**：报表大屏·经营利润。**路径**：报表大屏 → 点「本月」→ 看利润数字与趋势线（损耗单列不混淆）。
2. **场景**：供应商集体涨价，几十个商品要调售价。**解决**：批量改价。**路径**：商品管理 → 勾选商品 → 批量改价 → 按比例上调 → 确认。
3. **场景**：月底和老王对账，他不认账。**解决**：A4 对账单。**路径**：对账单 → 客户对账单 → 选老王 → 选月份 → 打印/存 PDF 发给他（期初期末+每笔往来+退货红冲都在）。
4. **场景**：想知道谁欠我钱、欠多少。**解决**：待办页或往来单位。**路径**：待办 → 谁欠我钱；或 往来单位 → 客户按欠款降序 → 展开看未清单据 → 订单里直接收欠款。
5. **场景**：从旧系统/Excel 搬家，300 个商品不想手敲。**解决**：AI 批量导入。**路径**：批量导入 → 选品类 → 粘贴 Excel 整片 → AI 解析 → 勾选确认 → 入库。
6. **场景**：客户微信发来订货消息一长串。**解决**：文本记账·客户订货模式。**路径**：文本记账 → 选「客户订货消息」→ 粘贴 → AI 解析 → 确认入账（自动生成销售单扣库存）。
7. **场景**：收摊了记今天的杂账（摊位费、进的面粉、卖出没入系统的）。**解决**：文本记账·随手记。**路径**：文本记账 → 打一段话 → AI 拆成进/销/支三类 → 勾选确认。
8. **场景**：卖了个没建档的新货。**解决**：文本记账顺手建档。**路径**：AI 解析后该行显示「没档案」→ 勾「顺便建档」→ 确认后档案自动建好且扣库存。
9. **场景**：换行业/加品线（水果店想加卖鲜花）。**解决**：AI 配字段。**路径**：品类管理 → 新建品类 → 输「卖鲜花的」→ AI 生成字段 → 改改保存。
10. **场景**：熟客拿货价和散客不一样。**解决**：专属价。**路径**：往来单位 → 展开该客户 → 设专属价（可按规格）→ 之后 AI 记账/开单自动用他的价。
11. **场景**：怀疑库存不对，想盘一次。**解决**：盘点。**路径**：盘点 → 新建盘点 → 逐规格填实盘数 → 提交（差异自动调库存并留痕）。
12. **场景**：想看哪天进钱多、哪天亏。**解决**：收益日历。**路径**：收益日历 → 月视图看每日净额 → 点某天看逐笔 → 点某笔直接跳到那张单。
13. **场景**：想知道什么货该补了。**解决**：工作台补货卡/AI 问生意。**路径**：工作台 →「该补货了」卡一键开进货单；或右栏问「什么货该补了」（按 14 天销速算）。
14. **场景**：给员工开账号但不想让他看见利润。**解决**：员工账号权限。**路径**：设置 → 员工管理 → 新建员工账号（员工登录后自动看不到利润/资金流水/AI 问生意/导出）。
15. **场景**：客户退货。**解决**：订单退货。**路径**：订单管理 → 搜单号或客户名 → 详情 → 退货 → 选行选数量（库存回增、欠款冲减、多收退款）。
16. **场景**：老花眼看不清字。**解决**：文字大小。**路径**：设置 → 外观与语言 → 文字大小选「特大」（整个界面即时放大）。
17. **场景**：找一张只记得客户名的单子。**解决**：全局搜索。**路径**：任意页面 Cmd+K → 输客户名 → 回车直开订单详情。
18. **场景**：怕数据被平台绑架。**解决**：全量导出。**路径**：顶栏「导出数据」→ 下载 JSON 全量（承诺永久免费可导）。
19. **场景**：进货时供应商赊账，月底统一付。**解决**：进货欠款。**路径**：进货管理 → 建单时少付/不付 → 月底「欠供应商」筛选 → 付欠款。
20. **场景**：白天太忙，想知道今天流水再走。**解决**：工作台/待办。**路径**：打开即见今日销售额/订单数/毛利，右栏最近动态逐笔滚动。
